## How It Works

| Step | Detail |
|------|--------|
| 1. Data Cleaning | Handles missing values, range-format sqft values, and rare locations |
| 2. Outlier Removal | Removes price-per-sqft outliers by location and filters BHK anomalies |
| 3. Feature Engineering | Encodes Bengaluru localities using one-hot encoding |
| 4. Model Selection | Compares Linear Regression, Lasso, and Random Forest models |
| 5. Serving | Flask REST API connects the ML model with the Streamlit frontend |

## Tech Stack

| Layer | Technology |
|------|------------|
| Data Processing | Pandas, NumPy |
| Machine Learning | Scikit-learn |
| Models | Linear Regression, Lasso, Random Forest |
| Backend / API | Flask, Flask-CORS |
| Frontend | Streamlit, Plotly |

## Dataset

- **Source:** Bengaluru House Data
- **Features:** Location, total_sqft, BHK, bathrooms, balcony, area type, availability, society, and other property details
- **Target:** House price

## Disclaimer

The predictions generated by this project are estimates based on historical housing data. They may not reflect actual market prices and should not be considered the sole basis for financial decisions.
